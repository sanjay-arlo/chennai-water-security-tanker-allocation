# Stakeholder Map

| Stakeholder | Decision need | Key KPI | Engagement |
|---|---|---|---|
| Water operations | Where to increase supply | Storage %, tanker MLD | Daily / operational |
| Tanker dispatch | Which zones need support | Tanker supply MLD, demand MLD | Daily |
| Planning / resilience | Where to invest | Persistent stress, rainfall deficit | Weekly |
| Finance / programme | Where to fund interventions | Priority zones, scenario cost | Monthly |
| Data / BI | Is the dashboard trustworthy? | Completeness, reconciliation, refresh status | Each release |

## RACI-style ownership

**Responsible:** Data / BI prepares the analytical product.  
**Accountable:** Water operations owner approves operational thresholds.  
**Consulted:** Planning, tanker dispatch and finance.  
**Informed:** Leadership and programme stakeholders.
